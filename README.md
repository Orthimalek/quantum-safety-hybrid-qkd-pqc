# Two Roads to Quantum Safety — Hybrid E91-QKD + ML-DSA

Simulation code, data, and figures for the paper:

**"Two Roads to Quantum Safety: A Hybrid E91-QKD + ML-DSA Architecture with CHSH/QBER Eavesdropping Detection and Threshold Co-Optimisation"**

Vinit Datta Rane¹, Shuchona Malek Orthi², Mehrdad S. Sharbaf³
¹ California State University, Dominguez Hills · ² Westcliff University · ³ California State University, Dominguez Hills

Archived on Zenodo: https://doi.org/10.5281/zenodo.20144465 (all versions)

---

## Overview

This repository contains a discrete-event simulator that evaluates a hybrid
quantum-safe architecture pairing the entanglement-based **E91 QKD** protocol
with **ML-DSA (FIPS 204, Level 3)** authentication. It reproduces every table
and figure in the paper, including secret-key rates, CHSH/QBER detection
probabilities, finite-key analysis, abort-threshold co-optimisation, and a
Qiskit statevector validation of the analytical CHSH model.

All results use random **seed = 42** and are fully reproducible.

---

## Which script to run

| Script | Purpose |
|---|---|
| **`simulation_complete_v2_rigorous.py`** | **Current / canonical.** Reproduces all tables and figures in the latest paper, using the rigorous composable finite-key bound (Tomamichel / Renner / Hayashi–Tsurumaru / Devetak–Winter). **Use this one.** |
| `simulation_complete_v2.py` | Previous version; uses the simplified √n finite-key heuristic. |
| `simulation_complete.py` | Initial version. |
| `fp_validation.py` | Standalone 100,000-trial false-positive validation at the optimised operating point. |
| `wilson_ci.py` | Wilson confidence-interval helper. |

The rigorous script reports `n_min ≈ 9.92×10³` bits (vs. the heuristic
`1.12×10⁵`); the heuristic value is retained in the paper only as a
conservative comparison.

## Quick start

```bash
git clone https://github.com/Orthimalek/quantum-safety-hybrid-qkd-pqc.git
cd quantum-safety-hybrid-qkd-pqc

pip install -r requirements.txt
# or: pip install numpy scipy matplotlib qiskit qiskit-aer

python simulation_complete_v2_rigorous.py
```

Running the script prints Tables II–VII to the console and writes all figures
(PNG at 600 DPI + PDF vector) and CSV data files to the current directory.

## Key results (seed 42)

- Hybrid/PQC crossover at **d ≈ 27.4 km**
- Optimised abort thresholds: **CHSH = 2.66, QBER = 2.33%**
- Detection at p = 0.05 improves **64.5% → 75.6%** (+11.1 pp absolute, 17.2% relative)
- 100,000-trial false-positive rate **0.392%** (95% Wilson CI [0.355%, 0.433%])
- Rigorous finite-key **n_min ≈ 9.92×10³ bits**
- ML-DSA overhead **< 0.25%** per protocol round
- Recommended deployment range **≤ 50 km**
